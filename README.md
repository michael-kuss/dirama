Digital Radio Manager (DiRaMa)
==============================

Functions
---------

- IN:
  - Get title information from e.g. mAirList
  - Several stations addressable
  - Merge 2 Stations to one on demand (broadcast)
- OUT:
  - Create playlist website template to be pushed via FTP/SFTP
  - Show RDS Text on supported devices
  - Show DAB+ Text on supported multiplex
